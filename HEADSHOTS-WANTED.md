# Headshots still wanted

`headshots/<key>.webp`, where the key is the player's name reduced to letters
and digits, lower case, with any generational suffix dropped — so
`Will Anderson Jr.` is `willanderson.webp` and `T.J. Watt` is `tjwatt.webp`.
Around 176px square is right; the card crops to the head at 132.

Drop files in, run `./build.sh`, done — `src/shots.js` is generated from the
directory. Anyone without a file gets his initials on his team's colour, which
is why the set can be completed a few at a time.

The 79 already there came from the HUB's set, which is a fantasy one: every
name below is a defender, which is why DPOY is the award still showing
initials.
